# Ten-Four 比較・取り入れ候補タスク（2026-09-25）

参考: https://tenfour-poker.com/ （公開LPと画面画像のみ確認。ゲーム内はログインが必要なため未確認）
Ten-Four = 6人制キャッシュゲーム + Fast Fold。本作 = ヘッズアップ1対1のトーナメント形式ランクマ。
デザインや画像をそのまま複製するのではなく、「機能・考え方」を取り入れる前提。

難易度: S=数時間 / M=半日〜1日 / L=数日
おすすめ: ◎=ぜひ / ○=あると良い / △=後回し可 / ×=本作には合わない
